Proposed change to the design language
These use a curved, minimal language — 12–22px radii and pill controls — against the flatter 2px / 4px radii agreed earlier. Treat the set as a proposal on shape only. Colour, spacing scale, type hierarchy and the tri-state semantics are unchanged.
